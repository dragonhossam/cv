# دليل رفع ونشر نظام CV Maker Pro على استضافة Hostinger

هذا الدليل يوضح لك بالخطوات كيفية رفع وتشغيل المنصة على استضافتك في Hostinger (باستخدام PHP وMySQL)، مع ربط نظام الدفع اليدوي بفودافون كاش ولوحة تحكم الإدارة.

---

## 1. الملفات الجديدة في هذا التحديث

1. `hostinger-export/schema.sql`: ملف قاعدة البيانات لإنشاء جداول الطلبات والإعدادات.
2. `hostinger-export/config.php`: ملف الاتصال بقاعدة البيانات وحماية الاستعلامات ضد SQL Injection.
3. `hostinger-export/api_orders.php`: ملف معالجة الطلبات، منع تكرار رقم العملية، وفحص حالة الطلب.
4. `dist/`: ملفات الواجهة الأمامية الكاملة المبنية والمحسنة لتعمل بأقصى سرعة على أي متصفح وجوال.

---

## 2. خطوات إنشاء قاعدة البيانات على Hostinger

1. ادخل إلى لوحة تحكم **Hostinger hPanel**.
2. توجّه إلى قسم **Databases (قواعد البيانات)** -> **MySQL Databases**.
3. أنشئ قاعدة بيانات جديدة:
   - **Database Name**: مثلاً `cvmaker_db`
   - **Username**: مثلاً `cvmaker_user`
   - **Password**: كلمة مرور قوية
4. بعد إنشاء قاعدة البيانات، انقر على زر **Enter phpMyAdmin**.
5. داخل phpMyAdmin، اختر قاعدة البيانات المنشأة ثم اضغط على تبويب **Import (استيراد)**.
6. اختر ملف `schema.sql` من هذا المجلد واضغط **Go / استيراد**.
   - سيتم إنشاء جدولي `orders` و `settings` تلقائياً مع البيانات الافتراضية.

---

## 3. إعداد الاتصال ورقم محفظة Vodafone Cash

1. افتح ملف `config.php`:
   - عدّل `DB_NAME` إلى اسم قاعدة البيانات الخاصة بك.
   - عدّل `DB_USER` إلى اسم المستخدم.
   - عدّل `DB_PASS` إلى كلمة المرور الخاصة بقاعدة البيانات.
2. لتعديل رقم محفظة فودافون كاش مباشرة:
   - يمكنك تعديله بسهولة من خلال لوحة الإدارة في الموقع (انقر على "لوحة تحكم الإدارة" وأدخل كلمة المرور `admin123` وعدّل الرقم وسعر الباقات).
   - أو من خلال جدول `settings` في phpMyAdmin بتعديل حقل `vodafone_cash_wallet`.

---

## 4. رفع ملفات الواجهة والنظام إلى استضافتك

1. شغّل أمر البناء في جهازك:
   ```bash
   npm run build
   ```
2. توجّه إلى **File Manager (مدير الملفات)** في لوحة Hostinger داخل مجلد `public_html`.
3. ارفع محتويات مجلد `dist/` إلى المجلد الرئيسي `public_html`.
4. أنشئ مجلداً باسم `api/` داخل `public_html` وضع فيه ملفات:
   - `config.php`
   - `api_orders.php`
5. أصبح موقعك جاهزاً ويعمل بكامل طاقته ومميزاته مع حماية البيانات ومنع تكرار المعاملات.

---

## 5. بيانات الدخول للوحة الإدارة
- الرابط: من القائمة العلوية اضغط على **لوحة تحكم الإدارة (Admin Dashboard)**
- كلمة المرور الافتراضية: `admin123` (يمكنك تغييرها من خلال إعدادات لوحة التحكم).
